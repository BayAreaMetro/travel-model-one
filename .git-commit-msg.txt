build: drop the NetworkWrangler dependency entirely

Its one unconditional caller in the shared pipeline (transitDwellAccess.py)
was already gone as of simplify_transit_master, and no `command:`/`script:`
step any project currently declares points at anything that imports it
either -- confirmed by grep, not just by the comment that used to justify
keeping it. The two utilities/ scripts that still `import Wrangler`
(cube_to_shapefile.py, createInputTripTablesFromHSR.py) are run by hand,
outside tm1 entirely, and were already dropped calls per README's own
"Dropped call" table.

Removes the git dependency (and the `allow-direct-references` hatch config
it alone required) from pyproject.toml, updates uv.lock, and fixes the
comments that still claimed it as a live dependency: `external.py`'s
`_argv` docstring, and `assignment/cube/transit.py`'s module docstring,
which described a `transitDwellAccess.py`/`wrangler_path` call that
`run_transit` itself no longer makes -- stale since whatever refactor
simplified it, evidently before this comment was updated to match.
