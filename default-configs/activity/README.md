# default-configs/activity

Canonical ActivitySim configuration — model specs (`*.csv`), coefficient files, and YAML
settings, ported from the CT-RAMP UEC workbooks.

Empty until **phase 4** (ActivitySim swap-in). Scenarios override individual files via
ActivitySim's config-inheritance chain: YAMLs merge key-by-key, CSVs replace wholesale.

See [`../../MIGRATION_NOTES.md`](../../MIGRATION_NOTES.md).
